The owner retains the original dated installation report, burn investigation,
September 11 review/repair board, September 12 addendum and final review with private
evidence. This repository deliberately summarizes those files instead of publishing
their private project names, machine paths, logs or memory contents.

The guard and adapter are portable derivatives of the working local files, with path
changes documented in README.md. The loopback host probe and aggregate usage census
were prepared during the September 12 verification. The census is a smaller reusable
extract; the private analysis also measured Read text, memory size and effort cohorts.

Install/version/license decisions belong to the recipient. The repository does not
redistribute RTK, CodeGraph, Headroom, model weights or client binaries.
